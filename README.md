# Population Distribution Visualization

##  Project Overview
This project visualizes the distribution of passenger data using the Titanic dataset. The main goal is to analyze demographic patterns such as age and gender distribution using data visualization techniques.

##  Objectives
- Visualize distribution of a continuous variable (Age)
- Visualize distribution of a categorical variable (Gender)
- Perform basic data cleaning
- Understand population trends using graphs

## 🛠 Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Visualizations Created
1. Age Distribution Histogram
2. Gender Distribution Bar Chart

## Dataset
The project uses the Titanic dataset which contains passenger demographic information.

Dataset Source:
https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv

##  How to Run the Project
Step 1: Install Required Libraries  
pip install pandas matplotlib seaborn  

Step 2: Run the Python File  
python distribution_visualization.py  

##  Project Output
- Shows age distribution of passengers using histogram
- Shows gender comparison using bar chart
- Helps understand demographic distribution patterns

##  Learning Outcomes
- Data cleaning techniques
- Exploratory Data Analysis (EDA)
- Data visualization basics
- Understanding categorical and continuous variables
